# 縦型タブ

*[English version](README.md)*

Chrome のサイドパネルに **縦型のタブ一覧をページプレビュー付きで**表示する Chrome 拡張機能
（Manifest V3）です。現在のウィンドウのタブが 1 枚ずつカードになり、favicon・タイトルに加えてページ
上部を切り取ったスクリーンショットが表示されるので、短く切り詰められたタイトルではなく「見た目」で
タブを見分けられます。

ビルド手順はありません。バンドラも npm 依存もなく、`extension/` フォルダをそのまま
**パッケージ化されていない拡張機能を読み込む**で読み込みます。

## 機能

- 現在のウィンドウのタブを **縦一列のカード**としてサイドパネルに表示します。
- **ページプレビュー**: 640 × 240 の JPEG（ページ上部を切り取ったもの）を、タブを表示したときに
  作成し、タイマーで更新します。一度も表示していないタブはプレースホルダのままです。
  `chrome://`・ウェブストア・他の拡張機能のページなど、Chrome が拡張機能に撮影を許可しないページは、
  空の黒い箱ではなくカード上に「プレビュー不可」と理由を表示します。
- **列数を選べます**: 1〜5 列。**既定は 1 列**で、1 行にカード 1 枚が幅いっぱいに並びます。
  選んだ列数に対してパネルが狭すぎるときは、カードを細くするのではなく収まる列数まで減らします。
- **カードの大きさを選べます**: 大きさを決めると、その幅で入るだけカードが並びます。
  Chrome の最小パネル幅では 160 px のカードが 2 列に収まり、縦タブとして一般的な密度になります。
- **タブの横にツール列**: パネルは 360 px より細くできないため、余る幅を、行では表せない情報に使います。
  後で開き直せる**タブの保存**、直前まで見ていた順に並ぶ**最近使ったタブ**、
  タブ数と中身が分かる**開いているウィンドウ**の一覧、開いているタブをサイトごとにグループへ入れる**自動グループ化**、
  **重複タブの検出**、数日触っていないタブをスリープさせる**放置タブの整理**、
  **音を使っているタブ**、タブ一覧を Markdown で書き出して貼ったリンクをまとめて開く**一覧の出し入れ**、
  再起動しても残る**メモ**。設定で選べ、チェックした順に上から並び、すべて外すと
  列ごと消えます。いずれもネットワークを使わず、プレビューに必要な権限以外は要求しません。
- **タブのロック**: 右クリックから「このタブをロック」。ロックしたタブは**このパネルからは閉じられません**
  — カードの × もコンテキストメニューの「閉じる」も「他のタブを閉じる」も重複タブの整理も対象外になります。
  ただし **Chrome のタブの × や Ctrl+W では閉じられます**。拡張は `tabs.onRemoved` を拒否できないためで、
  この制限は将来も変わりません。ロックはブラウザを再起動すると消えます（タブ ID が変わるため）。
- **別ウィンドウに切り離せます**: タブ一覧を独立したウィンドウで開きます。Chrome の 360 px の下限に
  縛られないので 260 px で開き、元のウィンドウのタブを操作し続けます。
- **ピン留めタブ**をアイコンのコンパクトグリッドで表示します。
- **タブグループ**を色付きのスタックとして表示し、折りたたみ・名前変更・色変更ができます。
- **閉じたタブのゴミ箱**からワンクリックで復元できます（閉じたウィンドウごと復元も可能）。
- タイトルと URL を対象とした**検索**。日本語の全角・半角を正規化して照合します。
  検索中は、**他のウィンドウにあるタブ**もリストの下にまとめて出ます。選ぶとそのウィンドウを前に出して開きます。
- **ドラッグ＆ドロップ**: 並べ替え、ピン留め／解除、グループへの追加・離脱、グループごとの移動、
  カードをリンクとして外部にドラッグ、外部リンクをドロップして新しいタブで開く。
- ローミングフォーカスによる**キーボード操作**と、2 つのグローバルショートカット。
- バックグラウンドで開いたタブの**未読ドット**、**休止（ハイバネート）**、**ミュート**、
  アクティブタブのクリックで直前のタブに戻るオプション。
- **英語・日本語**の UI（Chrome の UI 言語に追従）。
- システム設定に追従するダーク／ライトテーマ。

## インストール

**[Chrome ウェブストアからインストール](https://chromewebstore.google.com/detail/vertical-tabs/ofajdfikeepefnogjblgcecnmopanaak)** — これが一番簡単です。

手動で入れる場合や、開発版を試す場合は以下。

> **別のマシンに入れるなら** → **[導入手順](https://d4rulyn.github.io/vertical-tabs/install.html)**（ブラウザで開けます）。
> 最新の zip は [Releases](../../releases/latest) にあります:
> ```
> gh release download v1.0.0 --repo d4rulyn/vertical-tabs --pattern '*.zip'
> ```
> zip の作り方、読み込み、プレビューに必須の権限設定、更新のしかた、つまずいたときまで一枚にまとめてあります。
>
> 配布用 zip は Docker で作れます（ホストには何も入りません）:
> ```
> docker run --rm --user "$(id -u):$(id -g)" -v "$PWD":/work -w /work \
>   python:3.12-slim python tools/package.py
> ```
> `dist/vertical-tabs-<版>.zip` ができます。同じコミットからは常に同じバイト列になります。


Chrome ウェブストアでは配布していないため、ローカルから読み込みます。

1. このリポジトリを clone するかダウンロードします。
2. `chrome://extensions` を開きます。
3. 右上の**デベロッパーモード**をオンにします。
4. **パッケージ化されていない拡張機能を読み込む**をクリックし、リポジトリの
   **`extension/`** フォルダ（リポジトリのルートではありません）を選択します。
5. 任意ですが推奨: ツールバーのパズルアイコンから「縦型タブ」を**ピン留め**すると
   アイコンが常に表示されます。

Chrome 120 以降が必要です（`minimum_chrome_version: 120`）。

### パネルを開く

| 操作 | 動作 |
| --- | --- |
| ツールバーのアイコンをクリック | 現在のウィンドウでパネルを表示／非表示 |
| `Ctrl+Shift+E`（macOS は `Cmd+Shift+E`） | 同上 |
| `Alt+Shift+S` | パネルを開き、**検索ボックスにフォーカス** |
| 初回起動ページの「今すぐタブバーを開く」ボタン | そのウィンドウでパネルを開く |

ショートカットは `chrome://extensions/shortcuts` で変更できます。パネルはウィンドウごとに
ユーザー操作で開く必要があります（Chrome はユーザー操作なしのサイドパネル表示を拡張機能に許可しないため、
自動で開くことはできません）。

## パネルを右側に表示する

サイドパネルをどちら側に表示するかは、拡張機能ではなく **Chrome 自身**が決めます。ブラウザ側の設定で、
左から右へ書く言語のロケールでは既定が右側です。

1. **Chrome の設定 › デザイン**を開きます。
2. サイドパネルの位置の設定を **右**にします。

左側に表示されている場合、拡張機能は一度だけヒントを表示し、その設定ページを開くボタンを出します。
拡張機能からパネルの位置を変更する API は存在しないため、この方法しかありません。

---

## Chrome 標準の縦型タブを無効にする

Chrome のビルドによっては標準で縦型タブストリップを持っています。有効になっていると縦型のタブ一覧が
**2 つ**並んでしまうため、Chrome 側をオフにしてください（タブストリップを右クリック、または
設定 › デザイン から）。

この設定は拡張機能から読み取ることも変更することもできません。Chrome の横型タブストリップを
非表示にすることも、拡張機能にはできません。

## 使い方

### マウス操作

| 操作 | 対象 | 動作 |
| --- | --- | --- |
| 左クリック | カード／ピン留めタイル | そのタブをアクティブにする。すでにアクティブで「アクティブタブのクリックで直前のタブに戻る」が有効なら、直前のタブに戻る |
| `Ctrl`/`Cmd` + クリック | カード | 複数選択に追加／解除 |
| `Shift` + クリック | カード | 範囲選択 |
| 中クリック | カード／タイル | タブを閉じる（設定で無効化可能） |
| クリック | カードの × | そのタブを閉じる |
| クリック | スピーカーアイコン | ミュート／解除 |
| ダブルクリック | リストの空白部分 | 新しいタブを開く（設定で無効化可能） |
| 右クリック | カード・タイル・グループヘッダ・空白 | コンテキストメニュー |
| クリック | グループヘッダ | グループの折りたたみ／展開 |
| ダブルクリック | グループ名 | グループ名を変更 |
| クリック | グループの色見本 | Chrome の 9 色から選択 |
| クリック／中クリック | 下部の **+** | 新しいタブ（フォアグラウンド／バックグラウンド） |
| クリック | ゴミ箱アイコン | 最近閉じたタブ |
| クリック | 歯車アイコン | 設定 |

### ドラッグ＆ドロップ

- カードを上下にドラッグして並べ替え（複数選択中はまとめて移動）。
- **ピン留めグリッド**にドロップするとピン留め。ピン留めタイルをリストに戻すと解除。
- **グループの内側**にドロップするとグループに参加、グループの下にドロップすると離脱。
- **グループヘッダ**をドラッグするとグループごと移動。
- カードを**パネルの外**にドラッグすると、そのページの URL をドロップできます。
- **外部のリンク**をリストにドロップすると、その位置にバックグラウンドタブとして開きます。
- Chrome がネイティブのタブドラッグ中はすべてのタブ操作が失敗します。パネルは再試行し、
  それでも失敗した場合は短いエラーメッセージを表示します。

### キーボード（パネル内）

| キー | 動作 |
| --- | --- |
| `ArrowDown` / `ArrowUp` | 次／前のカード（2 列以上のときは 1 行分移動） |
| `ArrowLeft` / `ArrowRight` | 2 列以上のときは前／次のカード。1 列のときは、グループ内のカードで `ArrowLeft` がグループヘッダへ |
| `Home` / `End` | 最初／最後のカード |
| `Enter` / `Space` | フォーカス中のタブをアクティブにする |
| `Delete` / `Backspace` | フォーカス中のタブを閉じる |
| `Alt+ArrowUp` / `Alt+ArrowDown` | フォーカス中のタブを 1 つ移動 |
| `Shift+ArrowUp` / `Shift+ArrowDown` | 選択範囲を拡張 |
| `/`, `Ctrl+K`, `Ctrl+F` | 検索ボックスにフォーカス |
| `Ctrl+Shift+P` | **コマンドパレット**を開く。パネルでできることを名前で探して実行します |
| `Escape` | メニューを閉じる → 検索をクリア → リストからフォーカスを外す |
| `ContextMenu` / `Shift+F10` | フォーカス中のカードのコンテキストメニュー |

### プレビューについて

プレビューは「そのウィンドウで**表示されている**タブ」のスクリーンショットです。Chrome が拡張機能に
許可しているのはこれだけなので、次のようになります。

- タブを初めて表示してから少し後に、最初のプレビューが作成されます。
- 一度も表示していないタブはプレースホルダのままです。
- 切り替え**元**のタブのプレビューは、切り替えをパネルから開始した場合に更新されます
  （設定「切り替え前のタブのプレビューを更新する」）。
- プレビューは URL をキーに保存されるため、復元したタブ・複製したタブ・ブラウザ再起動後に
  復元されたタブは、すぐに保存済みの画像を表示します。
- ページ遷移の直後は、前のページのプレビューが一時的に淡色で表示されることがあります。

## 設定

パネルの歯車アイコンから開きます。設定は端末ごとに `chrome.storage.local` に保存されます。

| 設定 | 値 | 既定値 | 内容 |
| --- | --- | --- | --- |
| テーマ | システムに合わせる／ダーク／ライト | システムに合わせる | パネルの配色 |
| 列数 | 1〜5 | 1 | カードを何列で並べるか。選んだ列数に対してパネルが狭いときは、収まる列数まで自動的に減らします（カードは 96 px 未満になりません）。パネルを広げれば元の列数に戻ります |
| タブのプレビューを表示 | オン／オフ | オン | オフにするとカードは 34 px の行になります |
| ピン留めタブをコンパクトなグリッドで表示 | オン／オフ | オン | オフにするとピン留めタブもリスト内に表示されます |
| 中クリックでタブを閉じる | オン／オフ | オン | |
| 空白部分のダブルクリックで新しいタブを開く | オン／オフ | オン | |
| バックグラウンドで開いたタブに未読マークを付ける | オン／オフ | オン | |
| アクティブタブのクリックで直前のタブに戻る | オン／オフ | オフ | |
| この数以上のタブをまとめて閉じるときは確認する | 2〜50 | 5 | パネル内に確認バーを表示します |
| プレビューに写すもの | ページの先頭／読み込んだときの表示／いま見ている位置 | ページの先頭 | 下の「プレビューが写す場面」を参照 |
| アクティブタブのプレビューを更新 | タブ切り替え時のみ／30 秒／1 分／5 分 | 1 分 | 表示中タブのプレビューを最新に保ちます |
| 切り替え前のタブのプレビューを更新する | オン／オフ | オン | パネルから切り替えたとき、切り替え元をキャプチャします |
| タブバーを閉じている間もプレビューを作成する | オン／オフ | オン | オフにすると、パネルが開いていない間はキャプチャを停止します |
| Chrome を再起動してもプレビューを保持する | オン／オフ | オン | オフにするとブラウザ起動時にキャッシュを削除します |
| 次のサイトではプレビューを作成しない | ホスト一覧 | 空 | 1 行に 1 つ。`*.example.com` でサブドメインも含みます |
| プレビューのキャッシュを削除 | ボタン | — | 確認のうえ、保存済みプレビューをすべて削除します |

### プレビューが写す場面

プレビューは `captureVisibleTab` で撮るため、**ページの見えている部分だけ**が写ります。
再読み込みすると Chrome はスクロール位置を元に戻すので、記事の中ほどで F5 を押すと
本文の途中だけが写り、何のページだったのか分からなくなります。この設定はそのときの挙動を決めます。

| 値 | 挙動 |
| --- | --- |
| **ページの先頭**（既定） | プレビューをページの先頭に保ちます。表示位置が先頭にあるときに撮り、読み手がスクロールしている間は、既にある先頭のプレビューを**上書きしません**。まだプレビューが無いタブは位置に関わらず撮るので、カードが空のまま残ることはありません |
| 読み込んだときの表示 | ページを読み込んだ時点の表示のまま。ナビゲーションと手動更新でのみ差し替わります |
| いま見ている位置 | 読み手に追従します。撮るたびに差し替わるので、`アクティブタブのプレビューを更新` とタブの切り替えがそのまま反映されます |

先頭かどうかはページのスクロール位置を読んで判定します（`scripting` 権限、実測 5 ms、2 回目以降 1 ms）。
PDF ビューアなど拡張が触れないページでは判定できないため、その場合は「いま見ている位置」と同じ挙動になります。

「キーボードショートカット」セクションには現在の割り当てが表示され、
`chrome://extensions/shortcuts` へのリンクがあります。

## 権限

| 権限 | 必要な理由 | インストール時の警告 |
| --- | --- | --- |
| `sidePanel` | UI そのもの | なし |
| `tabs` | タブの `url` / `title` / `favIconUrl` の取得（この権限がないと API が返しません） | `<all_urls>` も要求しているため表示されません |
| `host_permissions: <all_urls>` | **プレビューを自動作成する唯一の方法**。ホストへのアクセス権がないと Chrome は `captureVisibleTab` を拒否します | 「すべてのウェブサイトのデータの読み取りと変更」 |
| `tabGroups` | タブグループの表示・折りたたみ・名前変更・色変更・移動 | —（実機未確認） |
| `sessions` | 閉じたタブのゴミ箱と復元 | —（実機未確認） |
| `storage` | 設定と内部状態の保存 | なし |
| `unlimitedStorage` | プレビューキャッシュを Chrome の自動削除対象から外す | なし |
| `favicon` | 読み込み中に favicon が空のときのフォールバック | なし |
| `alarms` | プレビューの定期更新とキャッシュの整理 | なし |
| `scripting` | 「プレビューに写すもの」が**ページの先頭**のとき、スクロール位置を読むため。読み取る値は `window.scrollY` ひとつで、ページを書き換えません | —（実機未確認） |

**要求していない**もの: `activeTab`、コンテンツスクリプト、`contextMenus`、`offscreen`。
ウェブページへのスクリプト注入は一切行いません。

「—」の 2 つは、実機 Chrome のインストール確認ダイアログを読んでから記入します
（[手動確認項目](#手動確認項目)参照）。未確認の文字列をこの README に書くことはしません。

## プライバシー

- プレビューがこのパソコンの外に出ることはありません。拡張機能専用の IndexedDB に保存され、
  読み出すのはパネルだけです。
- **ネットワーク通信を一切行いません**。解析・テレメトリ・リモートコード・外部フォント・外部画像・
  クラッシュ報告なし。インストール時も更新時も通信しません。天気とカレンダーのツールは一度作ってから
  削除しました。この一文を手放すほどの価値はないと判断したためです。`tests/specs/22-widgets.spec.js` が
  全ツールを表示した状態で通信ゼロを検証しているので、この約束は黙って腐るのではなくテストで落ちます。
- **シークレットウィンドウのタブは設定にかかわらずキャプチャしません。**
- `chrome://` ページ、Chrome ウェブストア、他の拡張機能のページ、`data:`、`about:blank` は
  Chrome 自体が許可していないためキャプチャしません。
- 機微なサイトは「次のサイトではプレビューを作成しない」に追加すれば、キャッシュにも残りません。
  追加した時点で、そのホストについて**すでに保存されているプレビューも削除**されます。
  初回訪問前に決めておく必要はなく、後から追加しても構いません。
- 「Chrome を再起動してもプレビューを保持する」をオフにすると、キャッシュはブラウザのセッション中だけ残ります。
- 「プレビューのキャッシュを削除」で即座にすべて削除できます。

## 既知の制限

- Chrome のサイドパネルは **360 px より狭くできず**、表示する側もブラウザの設定です。
  幅 170 px のような細いバーは実現できません。既定の 1 列はその幅広版にあたります。
  4 列にはおよそ 430 px、5 列にはおよそ 530 px のパネル幅が必要で、それ未満では
  カードを細くするのではなく列数を減らして表示します。
- Chrome 標準の横型タブストリップは拡張機能から非表示にできません。Chrome 標準の縦型タブも、
  拡張機能からは検出も切り替えもできません。
- キャプチャできるのは各ウィンドウの**アクティブタブだけ**で、Chrome が拡張機能に許可する頻度は
  全体で**およそ 1 秒に 1 回**です。そのためプレビューはタブ表示から 0.35〜1.5 秒後に現れ、
  ウィンドウが多い場合は順番に届きます。
- `tabs.onActivated` は「離れるタブ」を通知しないため、切り替え元のプレビューを更新できるのは
  切り替えをこのパネルから開始した場合だけです。`Ctrl+Tab` や標準タブストリップでの切り替えは
  定期更新に任されます。
- `chrome://` ページ、Chrome ウェブストア、他の拡張機能のページ、`data:`／`about:blank`、
  `file://`（「ファイルの URL へのアクセスを許可する」が必要）、シークレットタブ、除外ホスト、
  ポリシーでスクリーンショットが無効な場合はプレビューを作成できません。
- 最小化されたウィンドウは、再表示されるまでキャプチャされません。フォーカスされていない
  バックグラウンドのウィンドウは**通常どおりキャプチャできます**。
- 同じ URL の 2 つのタブは 1 つのプレビューを共有します。
- パネルはウィンドウごとにユーザー操作で開く必要があります（`sidePanel.open()` にはユーザー操作が必要）。
- ウィンドウ間のドラッグには、両方のウィンドウでパネルが開いている必要があります。
- タブグループの色は Chromium のパレットの近似値です（公式に hex 値が公開されていないため）。
- 「タブバーを閉じている間もプレビューを作成する」をオフにしたときの判定が正確なのは Chrome 142 以降です。
  それ以前のビルドでは「どのウィンドウでもパネルが開いていない」場合のみ停止します。
- Chrome 140 未満ではパネルの表示側を検出できないため、位置のヒントは表示されません。

## 開発とテスト

### ディレクトリ構成

```
extension/          製品そのもの。「パッケージ化されていない拡張機能を読み込む」対象
  manifest.json
  _locales/en|ja/   ユーザーに見える文字列すべて
  background/       MV3 service worker: キャプチャのスケジューリング・アラーム・メッセージング
  common/           worker / パネル / welcome ページで共有する純粋モジュール
  sidepanel/        パネル UI
  welcome/          初回起動ページ（オプションページも兼ねる）
tests/              Playwright E2E テストと Node ユニットテスト（Docker 専用）
tools/              アイコン生成（Pillow、Docker 内で実行）
docs/screenshots/   README 用画像
```

**ビルド手順はありません。** ファイルを編集し、`chrome://extensions` で再読み込みボタンを押して
パネルを開き直すだけです。

### テストの実行

すべて `mcr.microsoft.com/playwright:v1.62.1-noble`（Chromium 151 / Node 24）の中で実行します。
ホスト環境には何もインストールしません（このプロジェクトの絶対ルールです）。
リポジトリのルートで実行してください。

```bash
mkdir -p logs
export HOST_UID=$(id -u) HOST_GID=$(id -g)

# 1. テストイメージのビルド（初回は @playwright/test 1.62.1 のインストールも行われます）
docker compose -f tests/docker-compose.yml build 2>&1 | tee logs/e2e-build.log

# 2. ユニットテスト（純粋モジュール + i18n 整合性）— 数秒
docker compose -f tests/docker-compose.yml run --rm e2e npm run unit 2>&1 | tee logs/unit.log

# 3. Playwright スイート
docker compose -f tests/docker-compose.yml run --rm e2e 2>&1 | tee logs/e2e.log
```

出力:

- HTML レポート: `tests/output/report/index.html`
- スクリーンショット: `tests/output/screenshots/`
- 失敗時のトレース: `tests/output/artifacts/`

`tests/output/` と `logs/` は git 管理外です。コンテナはホストと同じ uid/gid で動くため、
生成されたファイルの所有者はそのままユーザーになります。

依存バージョンを固定する lockfile も、イメージの中で一度だけ生成します。

```bash
docker run --rm -v "$PWD/tests:/t" -w /t \
  mcr.microsoft.com/playwright:v1.62.1-noble npm install --package-lock-only
```

GPU 経路を確認したい場合のヘッドありスモークテストもあります（仮想ディスプレイが必要で、
無い場合はスキップされます）。

```bash
docker compose -f tests/docker-compose.yml run --rm e2e npm run test:headed 2>&1 | tee logs/e2e-headed.log
```

### テストの仕組み

- 拡張機能は `chromium.launchPersistentContext` に `channel: 'chromium'` と
  `--disable-extensions-except` / `--load-extension` を組み合わせて読み込みます。Playwright の
  既定の headless shell も、ブランド版 Chrome も `--load-extension` を無視するため、
  この組み合わせだけが動作します（この構成では `captureVisibleTab` も動作します）。
- キャプチャ系のテストは**2 ウィンドウ構成**を使います。フィクスチャのページは 2 つ目のウィンドウに置き、
  パネルのドキュメントは 1 つ目のウィンドウで通常のタブとして開いて可視状態を保ちます
  （`requestAnimationFrame`・`IntersectionObserver`・スクリーンショットに必要なため）。
  `?windowId=` でパネルの対象ウィンドウを指定します。実際のサイドパネルはクエリ文字列を持たないため、
  その本番経路も別のテストで検証しています。
- フィクスチャのページはコンテナ内の小さな HTTP サーバーが配信します。インターネット接続はなく、
  `about:blank` や `data:` は仕様上キャプチャできません。
- 拡張機能自身のキャプチャ制限が `MAX_CAPTURE_VISIBLE_TAB_CALLS_PER_SECOND` エラーを
  **一度も出さない**ことを検証し、別途、そのクォータが実在することも直接確認しています。
  直列化の間隔は、スクリーンショットが返ってきた時刻ではなく、制限機構自身が記録する
  呼び出し開始時刻（`vt/get-diagnostics` の `lastCallByWindow`）で検証します。
- ほとんどのテストはタブ 3〜6 個で動くため一覧がパネルに収まります。
  `15-list-scroll.spec.js` は 380 × 700 のパネルにあえて 18 個開き、一覧がスクロールすること、
  カードが本来の高さと 8:3 のプレビューを保ったままであること（潰されないこと）を検証します。

### アイコンの再生成

```bash
docker run --rm -v "$PWD":/work -w /work python:3.12-slim \
  sh -c "pip install -q pillow && python tools/make_icons.py"
```

PNG はリポジトリにコミットされているため、「パッケージ化されていない拡張機能を読み込む」に
ツールは不要です。

## トラブルシューティング

**拡張を更新・再読み込みしたらパネルが真っ白になった。** サイドパネルを一度閉じて、開き直してください。拡張を再読み込みすると、開いたままのパネル文書は Chrome に破棄されます（実測: 再読み込み
直後、パネルのページは閉じた状態になる）。上部のタイトルバーは Chrome 側の UI なので残り、中身だけが
消えます。設定もプレビューも失われていません。

**プレビューがまったく作成されない。** `chrome://extensions` を開き、この拡張機能の**詳細**から
**サイトへのアクセス**を「**すべてのサイト**」に設定してください。「クリックしたとき」や
「特定のサイト」では Chrome がすべてのスクリーンショットを拒否します。その場合パネルに黄色の
バナーが表示され、各カードにも理由が表示されます。管理対象の端末では `runtime_blocked_hosts`
ポリシーでホストがブロックされている可能性もあります。

**「ポリシーによりスクリーンショットが無効」という黄色のバナーが出る。** 管理ポリシー
（例: `DisableScreenshots`）がブラウザ全体でスクリーンキャプチャを禁止しています。
プレビューは 10 分間停止し、その後再試行します。

**特定のタブだけプレビューが作成されない。** URL を確認してください。`chrome://`、
Chrome ウェブストア、他の拡張機能のページ、`data:`、`about:blank` は常にキャプチャできません。
`file://` は拡張機能の詳細ページで「ファイルの URL へのアクセスを許可する」が必要です。
どのケースかはカードのツールチップに表示されます。

**ウィンドウを最小化するとプレビューが止まる。** 仕様です。ウィンドウを再表示すると再びキャプチャされます。

**開き直しても空、またはエラーになる。** `chrome://extensions` でこの拡張機能に **エラー** ボタンが
出ていないか確認し、再読み込みしてください。再読み込みした後は、上記のとおりパネルを開き直す必要が
あります。

**パネルが反対側に出る。** [パネルを右側に表示する](#パネルを右側に表示する)を参照してください。

## 手動確認項目

headless Chromium では自動化できない項目です。実機の Chrome で一度確認してください。

1. ツールバーアイコンでパネルが表示／非表示される。`Ctrl+Shift+E` / `Cmd+Shift+E` でも切り替わる。
   アイコンのツールチップに**現在の**割り当てが表示される。
2. `chrome://extensions` → 詳細 → **サイトへのアクセス** を「クリックしたとき」にすると、
   プレビューが停止し、サイトアクセスのバナーが表示され、各カードにも理由が出る。
   「すべてのサイト」に戻すと、再読み込みなしでプレビューが再開する。
3. `tabGroups` と `sessions` のインストール時警告の正確な文言を記録し、上の権限表に記入する。
4. Chrome の 設定 › デザイン にあるサイドパネル位置の設定項目の正確なラベルを記録し、
   この README にだけ記入する（パネル内のヒント文はバージョン非依存のままにする）。
5. この Chrome ビルドに標準の縦型タブがあるか、どこで切り替えるかを記録する。
6. パネルが左側にドッキングされているときだけ位置ヒントが表示され、右側では表示されない。
7. スクリーンショットを禁止するポリシー下で、プレビューが停止しポリシーバナーが表示される。
8. **実際のサイドパネル**内でのドラッグ＆ドロップ: 並べ替え、ピン留め、グループへのドロップ、
   グループヘッダのドラッグ、別ウィンドウへのドラッグ。
9. Windows と macOS のヘッドあり環境で、`image readback failed` ではなくプレビューが作成される。
10. まっさらなプロファイル・既定のパネル幅で 1 列表示になり、設定で 2〜5 を選ぶと
    すぐに反映される。
11. `chrome://` のタブのカードが、空の暗い箱ではなく錠前アイコンと「プレビュー不可」を
    ダーク／ライト両テーマで表示する。
